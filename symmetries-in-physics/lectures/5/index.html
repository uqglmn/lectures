corollaryThe character is a complete invariant

Compare your reasoning

Equivalent representations have equal characters (Proposition Basic properties(i)). Conversely, equal characters give equal multiplicities by Theorem Multiplicity formula, and representations with the same multiplicities are both equivalent to the same direct sum. ◻

04Character tables

All the character theory of a finite group fits in a single square array: the character table, with one row per irreducible character, one column per conjugacy class. Conventionally the first column is the class of the identity — so the first column lists the dimensions nin_ini​ — and the first row is the trivial character, all 111’s; class sizes are recorded above the columns, since the inner product needs them. The two orthogonality relations say that the table, suitably weighted, is a unitary matrix: rows are orthonormal with weights ∣C∣/∣G∣\abs C/\abs G∣C∣/∣G∣, columns with weights ∣G∣/∣C∣\abs G/\abs C∣G∣/∣C∣ — a complete error-check on every entry.

A systematic construction algorithm, with the tools now in hand:

  1. find the conjugacy classes and their sizes (Lecture 2);

  2. the number of irreducible representations equals the number of classes; solve ∑ini2=∣G∣\sum_in_i^2=\abs G∑i​ni2​=∣G∣ with n1=1n_1=1n1​=1 for the dimension pattern (Lecture 4), which in small groups is usually forced;

  3. write down the one-dimensional characters: these are homomorphisms G→C∖{0}G\to\C\setminus\{0\}G→C∖{0}, fixed by consistent assignments to generators compatible with the relations and with conjugacy (a one-dimensional character takes equal values on conjugate elements);

  4. fill the remaining rows from known subrepresentations (traces of explicit matrices) or by orthogonality to the rows already known — column orthogonality against the identity column is especially effective;

  5. verify the completed table against both orthogonality relations.

05The canonical decomposition and projection operators

Characters compute multiplicities; we now make them compute subspaces. Two notational conventions, used from here through Lecture 7: superscripts in parentheses, V(i)V^{(i)}V(i), always denote the abstract irreducible representations; subscripts, ViV_iVi​, denote the pieces of a given representation VVV defined next.

definitionIsotypic components

Let (ρ,V)(\rho,V)(ρ,V) be a representation. The isotypic component ViV_iVi​ of type iii is the sum of all irreducible invariant subspaces of VVV isomorphic to V(i)V^{(i)}V(i).

If V≅⨁imiV(i)V\cong\bigoplus_im_iV^{(i)}V≅⨁i​mi​V(i), the component ViV_iVi​ collects the mim_imi​ copies of V(i)V^{(i)}V(i), so dim⁡Vi=mini\dim V_i=m_in_idimVi​=mi​ni​. 5

Character. χ(g)=tr⁡ρ(g)\chi(g)=\tr\rho(g)χ(g)=trρ(g), a class function invariant under equivalence (Definition Character, Proposition Basic properties).

Orthogonality. Irreducible characters are orthonormal (first relation, Theorem First orthogonality relation); their columns obey a dual relation (Theorem Second orthogonality relation).

Multiplicities. ⟨χ,χi⟩\langle\chi,\chi_i\rangle⟨χ,χi​⟩ is the multiplicity of the iiith irreducible (Theorem Multiplicity formula); ∥χ∥2=1\lVert\chi\rVert^2=1∥χ∥2=1 iff the representation is irreducible (Corollary Irreducibility criterion).

Complete invariant. The character determines a representation up to equivalence (Corollary The character is a complete invariant).

Projectors. Character projectors give the canonical decomposition into isotypic components (Theorem Canonical decomposition and projectors).
