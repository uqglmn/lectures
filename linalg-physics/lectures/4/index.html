↳One map, many matrix descriptionsMotivation, scope, and the finite-dimensional setting

Lecture 3 ended with a liberating fact: a linear map is completely determined by what it does to a basis. If we also fix a basis of the target space, each of those output vectors becomes a column of coordinates—and stacking the columns gives a matrix. This lecture turns the informal dictionary “linear map ↔\leftrightarrow↔ matrix” into a precise isomorphism. Three payoffs follow. First, the rule for multiplying matrices is forced on us: it is exactly what composition of linear maps demands. Second, abstract spaces of linear maps turn out to be ordinary matrix spaces. Third, when we change basis the same operator acquires a new matrix related to the old one by similarity A′=P−1APA'=P^{-1}APA′=P−1AP.

The basis-dependence is the whole point for physics. In the finite/discrete core, choosing a basis chooses a coordinate representation; discretized position, momentum, and energy models are useful examples. Continuous position or momentum representations and continuous spectral measures require the Hilbert-space machinery of Lectures 13–14. The later finite lectures choose bases in which an operator’s matrix is as simple as possible.

02Composition becomes matrix multiplication

Matrices are added and scaled entrywise. With those definitions, M\MatM respects the linear structure.

So the “row-times-column” rule for matrix products is not an arbitrary convention: it is the only rule that makes matrices represent composition. Every property of matrix multiplication—associativity, distributivity, failure to commute—is inherited from the corresponding property of composing maps.

The map M\MatM from L(V,W)\Lin(V,W)L(V,W) to the matrix space Fm×n\F^{m\times n}Fm×n is linear, injective (a map with zero matrix kills every basis vector, hence is 000), and surjective (any matrix prescribes images of the basis vectors, which define a unique linear map, as in Lecture 3). Thus it is an isomorphism, and we can finally record the dimension promised in Lecture 3.

corollaryL(V,W)≅Fm×n\Lin(V,W)\iso\F^{m\times n}L(V,W)≅Fm×n

M\MatM is an isomorphism from L(V,W)\Lin(V,W)L(V,W) onto Fm×n\F^{m\times n}Fm×n. In particular dim⁡L(V,W)=(dim⁡V)(dim⁡W)\dim\Lin(V,W)=(\dim V)(\dim W)dimL(V,W)=(dimV)(dimW).

remarkWhy this mattersOpen the observation

This also connects map rank with Gaussian elimination. Reduce a matrix AAA to reduced row-echelon form R=EAR=EAR=EA, where EEE is invertible. Row operations preserve the row space, and EAx=0  ⟺  Ax=0EAx=0\iff Ax=0EAx=0⟺Ax=0, so they preserve all linear dependencies among the columns. If RRR has rrr pivots, its rrr nonzero rows are independent, while its pivot columns are independent and every nonpivot column is a combination of them. Thus both row rank and column rank of RRR equal rrr; the preserved row space and column dependencies give the same equality for AAA. Consequently elimination computes the basis-independent map rank.

03Invertibility and isomorphisms
definitionInvertible map, isomorphism

T∈L(V,W)T\in\Lin(V,W)T∈L(V,W) is invertible if there is S∈L(W,V)S\in\Lin(W,V)S∈L(W,V) with ST=IVST=I_VST=IV​ and TS=IWTS=I_WTS=IW​; such SSS is unique, written T−1T^{-1}T−1. An invertible linear map is an isomorphism, and V,WV,WV,W are isomorphic, V≅WV\iso WV≅W, if one exists.

A linear map is invertible exactly when it is bijective, as the next proposition records; the decisive fact for finite-dimensional spaces is then that a single number—the dimension—decides isomorphism.

T∈L(V,W)T\in\Lin(V,W)T∈L(V,W) is invertible if and only if it is both injective and surjective, and then its inverse function is automatically linear.

Compare your reasoning

definitionSimilar matrices

Square matrices A,A′A,A'A,A′ are similar if A′=P−1APA'=P^{-1}APA′=P−1AP for some invertible PPP. Similar matrices are exactly the matrices of one operator in different bases.

remarkWhy this mattersOpen the observation

Similarity compares the two matrices of one operator, using the same basis on domain and codomain. For a general T∈L(V,W)T\in\Lin(V,W)T∈L(V,W), with independent basis changes PPP on VVV and QQQ on WWW, the corresponding formula is A′=Q−1APA'=Q^{-1}APA′=Q−1AP, and such matrices are called equivalent. Equivalence is weaker: every rank-rrr map is equivalent to the block matrix with an r×rr\times rr×r identity in the top-left corner and zeros elsewhere. Similarity preserves the finer data—trace, determinant, eigenvalues—that only makes sense when domain and codomain coincide.

05The map, not the matrix

A matrix is a basis-dependent shadow of a linear map. Quantities that survive a change of basis—rank, trace, determinant, the characteristic and minimal polynomials, eigenvalues, and later canonical-form data—belong to the operator itself. Individual entries and coordinate patterns generally do not. The program of the next several lectures is to exploit this freedom: to hunt for a basis in which the matrix is diagonal, so that the operator’s action becomes transparent. In a finite-dimensional or discrete pure-point quantum model, an energy eigenbasis makes e−iH^t/ℏe^{-i\hat Ht/\hbar}e−iH^t/ℏ diagonal and the dynamics decouples into independent phases. Lectures 13–14 replace this ordinary matrix picture by generalized/spectral representations when continuous spectrum is present.

remarkWhy this mattersOpen the observation

In the later finite quantum model, a density matrix ρ\rhoρ is a positive trace-one operator representing a state, and a self-adjoint operator AAA represents an observable. Under the same basis change both transform simultaneously: ρ′=P−1ρP\rho'=P^{-1}\rho Pρ′=P−1ρP and A′=P−1APA'=P^{-1}APA′=P−1AP. Therefore tr⁡(ρ′A′)=tr⁡(P−1ρAP)=tr⁡(ρA).\tr(\rho'A')=\tr(P^{-1}\rho A P)=\tr(\rho A).tr(ρ′A′)=tr(P−1ρAP)=tr(ρA). Thus the expectation ⟨A⟩=tr⁡(ρA)\expval{A}=\tr(\rho A)⟨A⟩=tr(ρA) is independent of the chosen coordinates. Lecture 10 supplies the physical definitions and hypotheses; this is only a preview of the change-of-basis calculation.

Composition of maps becomes multiplication of matrices—which is what forces the row-by-column rule—so L(V,W)≅Fm×n\Lin(V,W)\iso\F^{m\times n}L(V,W)≅Fm×n and dim⁡L(V,W)=(dim⁡V)(dim⁡W)\dim\Lin(V,W)=(\dim V)(\dim W)dimL(V,W)=(dimV)(dimW).
